# 🚀 DevFolio

DevFolio is a modern online portfolio builder developed with **PHP (OOP)**, **MySQL**, and **MVC Architecture**. It enables developers, designers, and freelancers to create, customize, and publish professional portfolio websites through an intuitive dashboard—without writing code.

## ✨ Features

- 🔐 Secure Authentication (Login & Registration)
- 👤 User Dashboard
- 🖼️ Hero Section Management
- 🙋 About Section
- 💼 Project Management
- 🎓 Education Management
- 🌐 Social Media Links
- 📧 Contact Section
- 🎨 Responsive Portfolio Template
- 🔗 Public Portfolio via Username
- 📱 Mobile-Friendly Design
- 🛡️ Secure Password Hashing
- 👥 Multi-User Support
- ⚡ Built with PHP OOP & MySQL

## 🛠️ Tech Stack

- PHP (Object-Oriented Programming)
- MySQL
- HTML5
- Tailwind CSS
- JavaScript
- jQuery
- MVC Architecture

## 🌍 Portfolio URL

Each user has their own public portfolio.

Example:

```text
http://localhost/DevFolio/portfolio/?username=lina
```

## 🚀 Getting Started

1. Clone the repository

```bash
git clone https://github.com/linna-22/DevFolio.git
```

2. Import the database into MySQL.

3. Configure your database connection in:

```text
config/db.php
```

4. Start your local server (WAMP, XAMPP, or Laragon).

5. Open the project:

```text
http://localhost/DevFolio
```
